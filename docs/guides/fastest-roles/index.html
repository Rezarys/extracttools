Which classes level fastest?

Players do not agree, and we show both sides. reported by players, not official

  • "Assault, Support, and medic are all possible to level quickly and early through class actions. Recon no" (Steam review, October 1, 2026).
  • "The worst offender easily being assault, the core PVP class of the game, because you really only level it by getting kills [...] while nearly every other class gets it from more than just 1 way (including vehicle classes; either ferry players or drop off cargo)" (Steam review, October 1, 2026).

They disagree on Assault: quick to level for the first, the slowest for the second. The first also finds early Recon slow; the second says a class that earns XP in several ways levels more easily than one that earns it only from kills.

Measure your own XP per match in each class and compare them in the calculator.
