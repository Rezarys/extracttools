Is it worth starting late?

Players who joined late describe a hard start. reported by players, not official

  • "After playing for more than ten hours, they may still not even have Class 3 armor" (Steam review, October 2, 2026).
  • "I would only say play this game when server wipes happens" (Steam review, October 2, 2026).

Before Season 2, players expected progression and unlocks to reset for everyone on October 15, which would have put new players level with the rest of the server. Season 2 went live on that date, but the official patch notes we read do not mention a general wipe, so we cannot confirm that everyone started again from zero (details).

No next wipe date had been announced when this page was updated on October 15, 2026. A squad helps either way.
