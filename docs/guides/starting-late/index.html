Is it worth starting now, before the wipe?

Players who joined late describe a hard start. reported by players, not official

  • "After playing for more than ten hours, they may still not even have Class 3 armor" (Steam review, October 2, 2026).
  • "I would only say play this game when server wipes happens" (Steam review, October 2, 2026).

The fact that changes the answer: on October 15, progression and unlocks are reported to reset for everyone. A player who starts then starts level with the rest of the server, apart from anything that is kept.

If you start before, the hours you put in now teach you the game but the unlocks go away. A squad helps either way.
